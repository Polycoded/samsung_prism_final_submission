# Messy conference evaluation kit

Upload both source documents in **Organizer evaluation lab**, then select
`benchmark.json` and run it. The set deliberately contains draft contradictions,
changed times, similar network names, mixed layouts, dense operational wording,
punctuation-free questions, two compound questions, and one unsupported request.

Questions include `umm`, `uh`, `erm`, and immediate word repetitions. The runtime
shows the raw text and deterministic cleaned interpretation in telemetry; it does
not use an LLM to rewrite the question.

This is a fictional, author-known stress demonstration. Samsung can replace the
documents and benchmark with its own corpus and labels. Expected citation IDs use
`filename stem §heading`, matching the upload UI's visible citation convention.
